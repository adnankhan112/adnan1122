My Assignment: Video, Audio and Image in HTML

This page shows how to add video, audio, and images using HTML.

1. Image Tag (<img>)

The <img> tag shows a picture on the page.

2. Video Tag (<video>)

The <video> tag plays my video file: myvideo.mp4

3. Audio Tag (<audio>)

The <audio> tag plays a sound file.

What the Code Looks Like:

<img src="pic.jpg" alt="My Image">

<video controls>
  <source src="myvideo.mp4" type="video/mp4">
</video>

<audio controls>
  <source src="song.mp3" type="audio/mpeg">
</audio>
